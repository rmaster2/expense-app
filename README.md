# 경비청구 시험판 (v0.1)

휴대폰으로 영수증을 찍어 경비 내역을 기록하는 프로그램입니다.
**혼자 쓰면서 검증하는 시험판**이며, 전 직원용이 아닙니다.

---

## 이 시험판으로 확인하려는 것

기능을 쓰려고 만든 것이 아니라, **다음 네 가지가 되는지 확인하려고** 만들었습니다.
이게 안 되면 뒤에 무엇을 만들어도 소용이 없습니다.

| 확인할 것 | 왜 중요한가 |
|---|---|
| 휴대폰에서 카메라가 제대로 열리는가 | 안 되면 촬영 방식 자체를 바꿔야 합니다 |
| 영수증 40장을 담아도 저장 공간이 버티는가 | 용량 한계를 알아야 사진 화질을 정할 수 있습니다 |
| **한 달 뒤에 열어도 자료가 남아 있는가** | 경비 정리는 월 1회 업무라 가장 중요합니다 |
| 홈 화면에 추가하면 앱처럼 열리는가 | 전 직원 배포 방식이 여기서 갈립니다 |

---

## 준비물

- GitHub 계정 (없으면 아래 1단계에서 만듭니다. 무료입니다)
- 컴퓨터 (파일을 올릴 때만 씁니다)
- 안드로이드 휴대폰

---

## 1단계 · GitHub 계정 만들기

이미 계정이 있으시면 2단계로 넘어가십시오.

1. 컴퓨터에서 `github.com` 에 접속합니다.
2. 오른쪽 위 **Sign up** 을 누릅니다.
3. 이메일, 비밀번호, 사용자 이름(영문)을 입력합니다.
   - 사용자 이름은 나중에 주소에 들어갑니다. 예를 들어 `namkim` 으로 정하면
     주소가 `namkim.github.io/...` 가 됩니다.
4. 이메일로 온 인증 번호를 입력하면 끝입니다.

---

## 2단계 · 저장소 만들기

저장소(Repository)는 **파일을 넣어두는 폴더**라고 생각하시면 됩니다.

1. 로그인한 상태에서 오른쪽 위 **＋** → **New repository** 를 누릅니다.
2. **Repository name** 에 `expense-app` 이라고 입력합니다.
3. **Public** 을 선택합니다.
   - 무료로 쓰려면 공개여야 합니다. 이 시험판에는 회사 이름도 직원 이름도
     들어 있지 않으므로 공개해도 문제가 없습니다.
4. 아래 **Create repository** 를 누릅니다.

---

## 3단계 · 파일 올리기

1. 방금 만든 저장소 화면에서 **uploading an existing file** 이라는 파란 글씨를 누릅니다.
   - 안 보이면 **Add file** → **Upload files** 를 누르셔도 됩니다.
2. 받으신 파일 **6개를 전부** 끌어다 놓습니다.

   ```
   index.html
   config.js
   manifest.json
   sw.js
   icon-192.png
   icon-512.png
   ```

   > **주의** — 폴더째로 올리지 마시고, 폴더를 열어서 **파일들만** 올리셔야 합니다.
   > 폴더째 올리면 주소가 한 단계 깊어져서 화면이 열리지 않습니다.

3. 아래 초록색 **Commit changes** 를 누릅니다.

---

## 4단계 · 인터넷 주소 만들기 (GitHub Pages)

1. 저장소 위쪽 **Settings** 를 누릅니다.
2. 왼쪽 목록에서 **Pages** 를 누릅니다.
3. **Branch** 항목의 드롭다운에서 `main` 을 고르고, 옆은 `/ (root)` 그대로 둔 뒤 **Save** 를 누릅니다.
4. **1~2분 기다립니다.** 그 뒤 새로고침하면 화면 위쪽에 주소가 나타납니다.

   ```
   https://사용자이름.github.io/expense-app/
   ```

5. 이 주소를 컴퓨터 브라우저에서 먼저 열어 화면이 나오는지 확인하십시오.

> 주소가 안 열리고 404가 뜨면, 대개 3단계에서 파일이 아니라 폴더를 올린 경우입니다.
> 저장소 첫 화면에 `index.html` 이 바로 보여야 정상입니다.

---

## 5단계 · 휴대폰에 앱처럼 설치하기

1. 위 주소를 휴대폰 **크롬**으로 엽니다.
   - 카카오톡 나에게 보내기로 주소를 보내면 편합니다.
2. 오른쪽 위 **⋮** (점 세 개) 를 누릅니다.
3. **홈 화면에 추가** 를 누릅니다.
4. 홈 화면에 생긴 아이콘으로 여십시오.

> **반드시 홈 화면 아이콘으로 쓰십시오.**
> 브라우저 탭으로 쓰면 자료가 지워질 수 있습니다.

---

## 6단계 · 데이터 보호 켜기

1. 앱을 열고 오른쪽 위 **⚙** 를 누릅니다.
2. **데이터 보호 설정** 이 `켜짐 (안전)` 인지 확인합니다.
3. `꺼짐` 이면 아래 **데이터 보호 켜기** 버튼을 누릅니다.

이 설정을 켜면 휴대폰이 저장 공간을 정리할 때 이 앱의 자료를 건드리지 않습니다.

---

## 사용법

- **＋ 영수증 추가** → 촬영 → 금액 입력 → 저장. 이게 전부입니다.
- 금액만 넣으면 저장됩니다. 나머지는 비워도 됩니다.
- 목록에서 항목을 누르면 수정하거나 지울 수 있습니다.
- 위쪽 **‹ ›** 로 달을 옮깁니다.
- 사진 없이 저장해도 됩니다. (통행료 자동정산처럼 영수증이 없는 경우)

---

## 영수증 인식 엔진 교체 (v0.6)

영수증 사진을 읽는 엔진을 한글 전용 인식 엔진(PaddleOCR)으로 바꿨습니다.

- 기존 방식(Tesseract)보다 특히 **금액 숫자**를 훨씬 정확하게 읽습니다. 실제 영수증 두 장으로
  비교해 본 결과, 금액·부가세·합계 숫자가 전부 정확하게 나왔습니다.
- 이 엔진도 무료이며, 사진을 서버로 보내지 않고 휴대폰(브라우저) 안에서만 처리합니다. 유료
  OCR API는 여전히 쓰지 않습니다.
- 처음 한 번만 인식 모델을 받는 데 몇 초 더 걸릴 수 있습니다(인터넷 필요). 받아온 모델은
  브라우저에 남아, 그 다음부터는 다시 받지 않습니다.
- 혹시 회사 네트워크가 특정 주소를 막고 있어 새 엔진을 못 받아오면, 자동으로 예전 방식
  (Tesseract)으로 바뀌어 인식 기능 자체는 계속 동작합니다. 어떤 방식으로 인식했는지는
  설정 화면(⚙) → **프로그램 정보** → **글자 인식 엔진** 에서 확인할 수 있습니다.
- 상호명처럼 장식적인 글자는 여전히 한두 글자 정도 틀릴 수 있습니다. 금액·날짜처럼 중요한
  값은 항상 확인 후 저장하십시오.

## 자동 채우기 오류 수정 (v0.5)

실제로 써보시고 알려주신 문제 두 가지를 고쳤습니다.

- **금액이 잘리는 문제**: "128,000"처럼 숫자 사이에 OCR이 공백을 넣는 경우(예: "128, 000") 앞부분("128")만
  잡히던 문제를 고쳤습니다.
- **지출처에 주소가 들어가는 문제**: 상호명 라벨이 없는 영수증에서 주소 줄을 상호명으로 잘못 채우던 문제를
  고쳤습니다. 이제 주소처럼 보이는 줄은 건너뛰고, 그래도 확실한 후보가 없으면 **비워 둡니다**(틀린 값을
  자동으로 채우는 것보다 안전하다고 판단했습니다).
- 계정과목은 여전히 직접 선택하셔야 합니다 — 영수증 글자만으로는 정확히 구분하기 어려워 자동화하지 않았습니다.

> 여전히 이상하게 채워지는 영수증이 있으면, 인식된 글자(붙여넣기 칸에 남아 있는 내용)를 그대로 알려주십시오.

---

## 영수증 글자 자동 채우기 (v0.4에서 개선됨)

처음에는 사진을 길게 눌러 텍스트를 복사하는 방식(v0.3)으로 만들었는데, 실제로 써보니
안드로이드/브라우저에 따라 그 메뉴 자체가 안 뜨는 경우가 있어(사진이 갤러리가 아니라
웹페이지 안에 떠 있기 때문입니다), v0.4부터는 **앱이 사진을 직접 읽는 방식**으로 바꿨습니다.
유료 OCR API는 여전히 쓰지 않습니다(무료 인식 프로그램을 그 자리에서 내려받아 씁니다).

1. 영수증을 촬영하거나 앨범에서 고릅니다
2. 입력 화면의 **사진에서 자동으로 읽기** 버튼을 누릅니다
   - 처음 한 번은 인식 프로그램을 받느라 몇 초~십몇 초 더 걸릴 수 있습니다 (인터넷 필요)
   - 이후에는 더 빨라집니다
3. 금액·날짜·지출처가 자동으로 채워집니다
4. **채워진 내용은 반드시 확인 후 저장하십시오.** 자동으로 저장되지 않으며, 인식이
   완벽하지 않을 수 있습니다

> 예전처럼 사진을 길게 눌러 복사한 글자를 직접 붙여넣고 **자동 채우기**를 눌러도 됩니다(그대로 남겨뒀습니다).
> 인식이 잘 안 되는 영수증 형식을 발견하시면 알려주십시오. 규칙을 계속 보완할 수 있습니다.

---

## 관리부 제출 파일 만들기 (v0.2에서 추가됨)

이번 업데이트로 생긴 기능입니다. 매달 마감할 때 이렇게 하시면 됩니다.

1. 제출하려는 달로 이동합니다 (위쪽 **‹ ›**)
2. 오른쪽 위 **⚙** 를 눌러 설정 화면을 엽니다
3. **제출자 정보**에 이름을 한 번만 입력합니다 (다음부터 자동으로 기억합니다)
4. **관리부 제출** 아래 **이번 달 제출 파일 만들기** 버튼을 누릅니다
5. 만들어진 파일(예: `경비제출_홍길동_2026-01.json`)을 메일플러그 결재에 첨부해 제출합니다

> 이 파일에는 사진이 들어가지 않습니다. 금액과 적요(지출 내용)만 담겨 있어 용량이 매우 작습니다.
> 백업 파일(사진 포함, 내 휴대폰 복구용)과는 다른 파일이니 헷갈리지 않도록 주의하십시오.

## 한 달 검증 방법

이 시험판의 핵심입니다. 아래대로만 해주시면 됩니다.

1. **오늘** — 앱을 설치하고 영수증 한두 장을 넣습니다.
2. **평소대로** — 결제할 때마다 그 자리에서 찍어 넣습니다.
3. **일주일에 한 번쯤** — ⚙ 화면에서 `사용 중인 용량` 을 확인합니다.
4. **한 달 뒤** — 앱을 열어 **자료가 그대로 남아 있는지** 확인합니다.
   ⚙ 화면의 `경과 일수` 와 `지난번 사용` 을 보면 며칠 만에 열었는지 알 수 있습니다.

**중간에 꼭 한 번은 백업 파일을 내려받아 두십시오.** (⚙ → 백업 파일 내려받기)
자료가 날아가는지 확인하는 시험이라, 실제로 날아갔을 때 되돌릴 수단이 필요합니다.

## 프로그램을 고치고 싶을 때

`config.js` 파일만 고치시면 됩니다. `index.html` 은 건드리지 않으셔도 됩니다.

| 고칠 내용 | 방법 |
|---|---|
| 계정과목 추가·변경 | `categories` 의 목록을 고칩니다 |
| 사진 화질을 높이고 싶다 | `imageQuality` 를 `0.85` 로 올립니다 (용량이 늡니다) |
| 사진 용량을 줄이고 싶다 | `imageMaxSide` 를 `1200` 으로 낮춥니다 |

**고친 파일을 올리는 방법**

1. GitHub 저장소에서 `config.js` 를 누릅니다.
2. 오른쪽 위 **연필 아이콘** 을 누릅니다.
3. 내용을 고칩니다.
4. 아래 **Commit changes** 를 누릅니다.
5. `sw.js` 파일도 열어서 맨 위 `expense-v1` 을 `expense-v2` 로 바꿔주십시오.
   이걸 해야 휴대폰이 옛날 화면을 계속 보여주지 않습니다.
6. 휴대폰에서 앱을 껐다 켜면 바뀐 내용이 적용됩니다.

## 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 화면이 안 열린다 (404) | 파일을 폴더째 올리지 않았는지 확인 |
| 고쳤는데 그대로다 | `sw.js` 의 버전 숫자를 올렸는지 확인 |
| 사진이 옆으로 눕는다 | 사진 아래 **↻** 버튼으로 돌립니다 |
| 저장이 안 된다 | ⚙ 에서 용량이 꽉 찼는지 확인 |
| 자료가 사라졌다 | **바로 알려주십시오.** 이 시험판이 찾으려던 문제입니다 |

## 이 시험판에 없는 기능

일부러 뺐습니다. 검증에 필요 없고, 각각 따로 확인할 사안이기 때문입니다.

- PDF 만들기
- 영수증 대지 배치 (전표 뒤에 영수증을 모아 붙이는 화면)
- 차량운행일지
- 관리부가 여러 명의 제출 파일을 한 번에 모아 자동 합산하는 도구 (제출 파일을 "만드는" 기능은 v0.2에 추가됨. 여러 명 파일을 "모으는" 도구는 아직 없음)
- 전자결재 연동

다만 **자료 구조는 처음부터 위 기능들을 염두에 두고 만들었습니다.**
나중에 기능을 붙일 때 지금 넣은 자료를 그대로 씁니다.
